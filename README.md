## 六、几个容易被忽略的延迟相关细节

**1. IPv4归属地是随机的。** 野草云坦言因为全球IPv4紧缺，可能给你分配APNIC、RIPE或AFRINIC的地址，但都宣告到香港，速度没区别。如果你对IP归属有强迫症，这点要提前知道。

**2. 流量是双向统计的。** 上行下行都算，别以为只算下载。流量用完限速1Mbps，对延迟敏感的业务来说基本等于不可用，所以选套餐时流量预算要留足。

**3. 网络类型可以切换，但要花钱。** 买了优质BGP想换精品BGP，需要联系客服重新分配IP，一次性服务费50元。不算贵，但不是免费的。

**4. 25端口发邮件要交保证金。** 最低150元保证金，取消服务器时全额退回。这是防Spam的措施，不是坑，但如果你打算搭邮件服务器要知道这个门槛。

**5. 不强制实名、不需ICP备案。** 但不能用VPN等匿名网络购买，注册资料要真实，否则可能被要求提供证件验证。
